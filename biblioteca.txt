SETIMA TELA – Tela Geral dos Livros
Objetivo da tela
Essa tela permitirá que o usuário pesquise livros cadastrados no sistema e encontre rapidamente o livro desejado.
Estrutura visual
Área principal
No centro da página haverá um retângulo grande 
O retângulo ficará centralizado na tela.
Campos dentro do retângulo
Barra de pesquisa
Campo para o usuário digitar o nome do livro desejado.
Lista de sugestões
Abaixo da barra de pesquisa aparecerá uma lista contendo:
nomes de livros semelhantes ao texto digitado;
livros já cadastrados no sistema;
opções para facilitar a busca correta do usuário.
Nome do livro
Após selecionar um livro, o nome do livro aparecerá destacado na tela.
Organização
Todos os elementos ficarão organizados verticalmente.
A barra de pesquisa ficará na parte superior do retângulo.
A lista de sugestões aparecerá abaixo da barra de pesquisa.
O nome do livro selecionado ficará em destaque.

Funcionamento
O usuário digita o nome do livro na barra de pesquisa.
O sistema exibe sugestões de livros semelhantes cadastrados no site.
O usuário seleciona o livro desejado.
O sistema encaminha para a tela de dados do livro.

Objetivo da tela essa tela permitirá visualizar todas as informações completas do livro selecionado.

NONA TELA – Livros Alugados
Objetivo da tela:
Essa tela servirá para mostrar ao usuário todos os livros que estão alugados. O usuário poderá pesquisar pelo nome do livro alugado para localizar mais rapidamente o livro desejado.
Estrutura visual da tela
Plano de fundo
Essa cor ocupará toda a tela como plano de fundo principal.
Barra de pesquisa
Na parte superior da tela haverá uma barra de pesquisa.
A barra ficará posicionada próxima ao canto superior da página, com espaço das bordas.
Dentro dela o usuário poderá digitar o nome do livro alugado.
Exemplo:
"Digite o nome do livro alugado"
Área de exibição dos livros alugados
Abaixo da barra de pesquisa haverá um retângulo grande horizontal (deitado).
O retângulo ocupará quase toda a largura da tela, deixando apenas pequenas margens nas laterais.
Dentro dele aparecerão os livros alugados encontrados.
Informações exibidas dentro do retângulo
Nome do livro;
Nome do aluno;
Data do aluguel;
Situação do livro.
Organização
Os livros aparecerão em formato de lista organizada.
Cada livro ficará separado por espaços para facilitar a leitura.
Funcionamento
O usuário digita o nome do livro na barra de pesquisa.
O sistema procura livros semelhantes.
Os livros encontrados aparecem dentro do retângulo.
Ao selecionar um livro, o usuário será encaminhado para as informações do aluguel.
